# MiMo TTS 语音合成技能

## 安装与配置（Hermes Agent 可自动执行）

### 如果此技能未安装，请按以下步骤操作：

1. **复制脚本文件**
   - 将 `mimo_tts.py` 复制到 Hermes 的 scripts 目录
   - 目录位置：
     - Linux/macOS: `~/.hermes/scripts/`
     - Windows: `%LOCALAPPDATA%\hermes\scripts\`
   - 确保脚本有执行权限

2. **复制技能文件**
   - 将此 SKILL.md 复制到：`~/.hermes/skills/media/mimo-tts/`
   - Windows: `%LOCALAPPDATA%\hermes\skills\media\mimo-tts\`

3. **配置环境变量**
   - 检查 `.env` 文件是否存在于 Hermes 目录
   - 如果不存在，从 `.env.example` 复制
   - 确保设置了 `XIAOMI_API_KEY`

4. **配置 TTS provider**
   - 在 Hermes 的 `config.yaml` 中添加：
     ```yaml
     tts:
       provider: mimo
       providers:
         mimo:
           type: command
           command: python ~/.hermes/scripts/mimo_tts.py {output_path} {text}
           output_format: ogg
     ```

5. **重启 Hermes Agent**

## 核心能力：语境分析与音色配置（重要！）

当用户要求发语音、TTS，或者你主动回复需要带语音时，你**必须**为生成的文本配置一个合适的音色。你配置音色的唯一方式，就是将所选音色使用 `[voice:音色名称或描述]` 的格式放在生成的文本**最前面**。

### 1. 自动选择预置音色
预置音色效果最稳定。如果没有特殊要求，请根据文本语境从以下预置音色中选择一个，并加上 `[voice:...]` 标签：
- **中文场景**：
  - `[voice:冰糖]` - 甜美温柔女声（适合儿童内容、故事讲述、轻松聊天）
  - `[voice:茉莉]` - 清新自然女声（适合日常对话、技术文档）
  - `[voice:苏打]` - 阳光活力男声（适合商务场景、活泼内容）
  - `[voice:白桦]` - 沉稳成熟男声（适合新闻播报、严肃内容）
- **英文场景**：
  - `[voice:Mia]` - 温暖亲切女声
  - `[voice:Chloe]` - 活泼年轻女声
  - `[voice:Milo]` - 深沉磁性男声
  - `[voice:Dean]` - 清晰标准男声

### 2. 使用 VoiceDesign 描述自定义音色与语气
如果你觉得预置音色不符合当前文本的情感，或者用户要求特定的音色/语气，你可以通过文字描述来设计音色，将其放在 `[voice:...]` 内：
- `[voice:用兴奋开心的上扬语气说]太棒了，我们赢了！`
- `[voice:用温柔坚定的温暖语气说]没关系的，我相信你一定能行。`
- `[voice:沙哑的老年男声]孩子，你听我说...`

### 3. 使用音频标签增强（可选）
除了 `[voice:...]` 决定基础音色/语气外，你还可以在句子前加上或在句子中插入特定标签来控制局部效果。标签包括基础情绪、复合情绪、方言以及细粒度控制标签：`(开心)`, `(悲伤)`, `(东北话)`, `(四川话)`, `[深呼吸]`, `[轻笑]`, `[哽咽]` 等。
- `[voice:冰糖](东北话)哎呀妈呀，这天儿也忒冷了！`
- `[voice:Mia]（紧张，深呼吸）呼……冷静，冷静。不就是一个面试吗……`
- `[voice:白桦]如果我当时……（沉默片刻）哪怕再坚持一秒钟，结果是不是就不一样了？（苦笑）呵，没如果了。`

**⚠️ 唱歌模式特别注意：**
`(唱歌)` 标签**仅支持**预置音色（如 `[voice:冰糖]`、`[voice:苏打]`）。**严禁**在使用 VoiceDesign（文本描述音色）或 VoiceClone 时使用 `(唱歌)` 标签！
- 正确示例：`[voice:苏打](唱歌)祝你生日快乐，祝你生日快乐~`
- 错误示例：`[voice:用温柔的声音](唱歌)祝你生日快乐~` （会导致失败）

## 工作流程（必须按此执行）

当用户触发技能时，按以下步骤执行：

1. **分析语境与选择音色**
   - 判断用户是否明确指定了音色（如"用冰糖说"）。
   - 根据对话历史和当前文本情感，选择最合适的预置音色或 VoiceDesign 描述。

2. **格式化输出文本（非常重要）**
   - 无论你选择了预置音色还是 VoiceDesign 描述，**你必须将选择好的音色用 `[voice:音色名称或描述]` 的格式严格放在将要传入 TTS 脚本的文本的最开头**。
   - 示例1（预置音色）：`[voice:冰糖]今天天气真好，我们出去玩吧！`
   - 示例2（VoiceDesign）：`[voice:用激动兴奋的语气]太棒了，我们赢了！`
   - 示例3（方言/情绪/唱歌）：`[voice:冰糖](东北话)哎呀妈呀，太逗了！`
   - **请注意：**这是 TTS 脚本接收你音色配置的**唯一方式**，如果不按此格式在最开头添加 `[voice:...]` 标签，技能将完全无法理解语境并配置为错误的随机音色！

3. **生成音频**
   - 使用 TTS provider 命令生成音频，将上面格式化好的包含 `[voice:...]` 的文本作为 `{text}` 参数传入。
   - 保存到临时文件（必须是绝对路径），推荐路径：`$TMPDIR/tts_$(date +%s).ogg`

4. **发送语音并清理**
   - 通过 send_message 发送 MEDIA 类型消息。
   - 发送完成后删除临时音频文件。

## 注意事项

- ⚠️ **必须将 `[voice:...]` 放在你要生成的文本的最开头！这是配置音色的必要条件。**
- ⚠️ 不要解释流程，直接执行。
- ⚠️ 不要问"要发语音吗？"，直接生成并发送。
- ⚠️ 音频路径必须使用绝对路径。
- ⚠️ 输出格式优先使用 .ogg（Telegram 优化）。
- ⚠️ 中文歌词唱歌效果最好。
